<h3 id="project1">Project 1: Adaptive Silent Communication using Vibration Pattern Recognition</h3>
<p>
  The Adaptive Silent Communication System using Vibration Pattern Recognition is an ESP32-based wireless system designed for silent communication. It converts short (S) and long (L) button presses into predefined patterns and transmits them between two ESP32 devices using ESP-NOW. The receiver recognizes the pattern, displays the corresponding message on an OLED, and provides vibration feedback. The system offers a simple, low-cost, and real-time communication solution without requiring Internet connectivity.
</p>
