<h3 id="project1">Project 1: Adaptive Silent Communication using Vibration Pattern Recognition</h3>
<p>
  The Adaptive Silent Communication System using Vibration Pattern Recognition is an ESP32-based wireless communication system designed to enable silent and discreet communication through predefined short- and long-press patterns. It converts short (S) and long (L) button presses into unique combinations that represent specific messages. These patterns are transmitted between two ESP32 microcontrollers using the ESP-NOW wireless communication protocol, which enables direct device-to-device communication without requiring an internet connection or Wi-Fi router. At the receiver, the system identifies the received pattern by comparing it with predefined patterns stored in its program. The corresponding message is displayed on an SSD1306 OLED display, while a vibration motor provides tactile feedback to the user. If an unrecognized pattern is received, the system can display an invalid-pattern message and provide an alert. The system integrates embedded programming, wireless communication, pattern recognition, visual display, and vibration feedback into a compact and low-cost prototype. It provides a practical approach to silent communication in situations where verbal communication may be inconvenient or difficult, with potential for future improvements in pattern recognition, communication capacity, portability, and feedback mechanisms.
